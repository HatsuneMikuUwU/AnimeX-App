## Kenapa AnimeX?

| Fitur Utama | Keunggulan |
| :--- | :--- |
| **Cepat & Ringan** | Buka aplikasi, cari judul, langsung nonton tanpa gangguan bloatware. |
| **Material 3 Expressive** | Antarmuka adaptif dengan warna dinamis (*Material You*) yang mengikuti tema sistem. |
| **Mode Offline** | Unduh episode favorit di latar belakang dan nikmati kapan saja tanpa kuota. |
| **Sinkronisasi MAL** | Progres nonton, rating, dan riwayat langsung terhubung otomatis ke MyAnimeList. |
| **Notifikasi Rilis** | Dapatkan pemberitahuan otomatis begitu episode terbaru rilis. |

---
## Fitur Lengkap
### Beranda & Eksplorasi
- **Baris Konten Dinamis**: `Lanjut Nonton` · `Episode Baru` · `Sedang Hangat` · `Judul Baru` · `Jadwal Hari Ini` · `Jas Por Yu` · `Paling Ditunggu` · `Populer`.
- **Eksplorasi Lengkap**: Cari berdasarkan *Kategori*, *Studio*, *Tahun*, dan *Tipe*.
- **Filter Musim**: Kategori tahun dilengkapi filter musim `Spring`, `Summer`, `Fall`, dan `Winter`.
- **Pencarian Cerdas**: Dilengkapi dengan riwayat pencarian untuk akses cepat.
### Pemutar Video & Detail Anime
- **Multi-Server & HLS**: Mendukung tautan langsung, protokol HLS, dan server embed.
- **Fitur Pemutar**: Kunci layar, mode *fullscreen*, pemutaran episode selanjutnya secara otomatis, dan pilihan kualitas video.
- **Detail Lengkap**: Sinopsis, statistik *views*, jumlah *favorite*, daftar karakter beserta pengisi suaranya.
### Pengelola Unduhan
- Unduh di latar belakang dengan indikator progres di bilah notifikasi.
- Kontrol penuh: *Pause*, *Resume*, *Retry*, atau *Cancel*.
- Pengelompokan berkas unduhan yang rapi per judul anime.
- Bebas pilih folder penyimpanan kustom.
### Integrasi MyAnimeList (MAL)
- Login langsung dan kelola *Animelist* kamu tanpa keluar dari aplikasi.
- Pembaruan otomatis episode terakhir yang ditonton ke akun MAL.
- Kelola status (`Watching`, `Completed`, `On Hold`, `Dropped`, `Plan to Watch`), skor, tag, dan catatan.
- Tampilan profil lengkap dengan statistik nonton.

## Teknologi & Arsitektur
AnimeX dibangun menggunakan standar pengembang Android modern:
- **Bahasa**: Kotlin
- **Desain UI**: Material Design 3 (Material You)
- **Pengelola Unduhan**: Background Service & Notification Manager
- **Integrasi API**: MyAnimeList API v2 & Custom Anime Parser

## Cara Instalasi
1. Buka halaman [**Releases**](https://github.com/HatsuneMikuUwU/AnimeX-App/releases/latest).
2. Unduh berkas `.apk` versi terbaru (pilih varian `universal` jika tidak yakin).
3. Buka berkas `.apk` di perangkat Android kamu, lalu izinkan opsi *Install from Unknown Sources* jika diminta.
4. Selesai! Selamat menonton.
